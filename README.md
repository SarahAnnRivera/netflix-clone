# Netflix Clone

**A responsive Netflix-inspired streaming application built with React, Vite, and Firebase.**

This project recreates core streaming-platform interactions, including user authentication, protected navigation, dynamic movie content, and video playback.

Built as an educational frontend project, it demonstrates component-based architecture, API-driven content, client-side routing, and responsive interface development.

## Features

- **User Authentication:** Registration, login, and persistent authentication using Firebase Authentication.
- **Protected Navigation:** Application routes and features accessible based on authentication state.
- **Dynamic Content:** Movie browsing and video content populated through API integration.
- **Video Player:** Dedicated player interface for viewing available video content.
- **Responsive Design:** Netflix-inspired layout adapted for different screen sizes.
- **Reusable Components:** Modular interface elements for navigation, movie cards, and page layouts.
- **User Feedback:** Toast notifications for relevant application events.

## Prerequisites & Installation

### Prerequisites

- Node.js 20.19+ or 22.12+ (Vite 8 requirement)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SarahAnnRivera/netflix-clone.git
   ```

2. Navigate into the project directory:

   ```bash
   cd netflix-clone
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure Firebase using the environment
   variables required by the application.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal,
   typically:

   http://localhost:5173

### Available Scripts

- `npm run dev` — Start the development server
- `npm run build` — Create a production build
- `npm run preview` — Preview the production build
- `npm run lint` — Run Oxlint
